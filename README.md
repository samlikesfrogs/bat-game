What is it:

A game where you, as a fox cowboy, kill a bunch of plants. Eventually these plants will drop seeds you can use for farming but the game loop is incomplete at the moment. 

Why I made it:

I like video games? Also as a born and bred Texan (this is not true), I am very invested in cowboy culture (I have been to maybe two rodeos) so this project is very meaningful frfr. I also think Stardew Valley is lacking in furries and guns.

Terra Week 1: Play in browser (https://samiiswriting.itch.io/oasis)
